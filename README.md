# WepawnAI-Plugin
WepawnAI-Plugin

WepawnAI is an AI-powered mod installation assistant that runs as a Mod Organizer 2 plugin. Enter a mod ID and WepawnAI will automatically analyze the dependency tree, guide you through the installation order, and sort your load order with LOOT — all in one place.

**No more struggling with mod installation in the age of AI — introducing WepawnAI, your AI-powered mod setup assistant.**
WepawnAI is an AI module that runs as a plugin inside Mod Organizer 2. Whether you're a beginner who finds mod installation overwhelming, or an experienced modder looking to save time — WepawnAI guides you through the entire process step by step.
**Requirements**
WepawnAI runs as an MO2 plugin, so Mod Organizer 2 is required. Vortex is not supported.
LOOT is not listed as a dependency, but it must be downloaded, extracted, and placed inside your MO2 folder. WepawnAI will guide you through this on first launch.
A personal Nexus Mods API key is also required. WepawnAI will walk you through obtaining one during the initial setup.
**AI Model**
WepawnAI runs on Gemma 4, an open-source AI model. Due to the embedded model, the total file size is approximately 5GB.
